## 后续修复：旧服务端返回 501

用户截图的英文错误来自 Rust `api_not_found`：未知接口返回 `501`、`code=not_implemented`。原安卓错误处理只识别无结构 404，且缺少旧版读取方式。

- [x] 新接口返回 501/not_implemented 或无结构 404 时，使用既有 `get_folder_conversation`、`fromIndex=0` 获取完整历史并在手机建立文件清单；不更改普通会话的分页和缓存。
- [x] 使用原始工作目录或当前文件夹解析相对路径；失败、在途工具不入清单，规范化路径后去重，保留较早文件。
- [x] 旧服务端无法提前检查文件时，将可用状态保留为未知，允许打开时检查；不把历史删除误当成当前不存在。
- [x] 401、403、500 不触发兼容读取；不完整历史明确报错，避免漏掉早期文件。
- [x] 补充 4 项路径识别单测和 4 项网络兼容回归，全量单测、Lint、APK 构建通过。
- [x] Android 15 模拟器实际收到 501 后自动恢复文件清单，搜索和代码远程预览通过。

修复后不要求必须先升级服务端；旧服务端只在文件管理页首次整理时传输完整会话，较大历史可能更慢。未操作用户真机或线上服务。
